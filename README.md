# 2025 Machine Learning

**A set of practical notebooks and scripts for core machine learning methods.**

## Overview

This repository collects coursework examples for regression, classification, clustering, model evaluation, regularization, and a PyTorch MNIST classifier. Each notebook or script is an independent exercise rather than a unified package.

## Key topics

- Compare two-way and three-way data splits with k-fold evaluation.
- Fit and visualize linear regression and regularization examples.
- Explore a custom Bayesian decision classifier and K-means clustering.
- Train a PyTorch model on selected MNIST digits.

## Tech stack

Python, Jupyter Notebook, NumPy, pandas, scikit-learn, Matplotlib, Seaborn, PyTorch, and torchvision.

## Installation and execution

```bash
python -m venv .venv
# Activate the environment for your shell, then:
python -m pip install jupyter numpy pandas scikit-learn matplotlib seaborn torch torchvision
jupyter notebook
```

Run the chosen notebook from top to bottom. The split-evaluation script and corresponding exercise expect a local `dummy_binary_classification.csv` with a `target` column; that dataset is not included. MNIST and Iris examples load their datasets through the respective libraries.
